# React

## Patterns

Use the `vercel-react-best-practices` skill for React and Next.js patterns: waterfalls, bundle size, re-renders and rendering cost.

## Performance loop

After you build or change a page, and whenever you are asked to make the app faster, read performance-loop.md and run it. It needs the `performance` skill from web-quality-skills:

```sh
npx skills add https://github.com/addyosmani/web-quality-skills --skill performance
```
